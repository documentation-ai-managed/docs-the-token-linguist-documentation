## Beginner-Friendly Tutorials

Start your linguistic technology journey with these foundational resources that break down complex concepts into manageable steps.

<Steps>
  <Step title="Understanding Tokens" icon="hash">
    Learn what tokens are and why they're fundamental to language processing.
    
    <Expandable title="Key Concepts" default-open="true">
      - Character vs. word vs. subword tokenization
      - Vocabulary size and its impact on model performance
      - Handling special tokens and unknown words
    </Expandable>
    
    <CodeGroup tabs="Simple Example,Advanced Example">
      ````python
# Simple word tokenization
text = "The Token Linguist helps developers."
words = text.split()
print(f"Words: {words}")
print(f"Count: {len(words)}")
      ````
      ````python
# Advanced subword tokenization
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained('bert-base-uncased')
text = "The Token Linguist helps developers understand tokenization."
tokens = tokenizer.tokenize(text)
ids = tokenizer.convert_tokens_to_ids(tokens)
print(f"Subword tokens: {tokens}")
print(f"Token IDs: {ids}")
print(f"Vocabulary coverage: {len(set(ids))} unique tokens")
      ````
    </CodeGroup>
  </Step>
  <Step title="Basic Preprocessing" icon="filter">
    Master text cleaning and normalization techniques essential for quality NLP.
    
    <Callout kind="tip">Always normalize your text before tokenization to ensure consistent results.</Callout>
  </Step>

      ````python
# Multilingual BERT example
from transformers import BertTokenizer, BertModel

tokenizer = BertTokenizer.from_pretrained('bert-base-multilingual-cased')
model = BertModel.from_pretrained('bert-base-multilingual-cased')

text = "Hello world! Bonjour le monde!"
tokens = tokenizer.tokenize(text)
print(f"Multilingual tokens: {tokens}")
      ````
      ````python
# XLM-RoBERTa for better multilingual support
from transformers import XLMRobertaTokenizer, XLMRobertaModel

tokenizer = XLMRobertaTokenizer.from_pretrained('xlm-roberta-base')
model = XLMRobertaModel.from_pretrained('xlm-roberta-base')

languages = ["English: Hello world", "French: Bonjour le monde", "Spanish: Hola mundo"]
for text in languages:
    tokens = tokenizer.tokenize(text)
    print(f"{text[:20]}... → {len(tokens)} tokens")
      ````
